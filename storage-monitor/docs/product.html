What it watches

01

Disk usage

Every mounted filesystem checked against WARN/CRIT thresholds you set — not a fixed default.

storage-monitor --json
02

Inode usage

Catches the failure disk-percentage alone misses: plenty of space, zero inodes left.

df -iP /var
03

Storage growth

Scheduled snapshots of the directories you care about, with alerts on sudden growth.

growth-tracker snapshot
04

Migration proof

Before/after checksums across an entire directory tree — a real PASS or FAIL, not a guess.

migration-verify after ./dst demo

Install it

LINUX / WSL
MACOS (HOMEBREW)
FROM SOURCE
$ curl -fsSL https://raw.githubusercontent.com/YOUR_GH_USER/storage-monitor/main/dist/get.sh | bash
$ brew tap YOUR_GH_USER/storage-monitor
$ brew install storage-monitor
$ git clone https://github.com/YOUR_GH_USER/storage-monitor.git
$ cd storage-monitor && sudo ./install.sh
